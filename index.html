php-parallax — Alpine apk repository

Version: main

This repository ships .apk packages built against the official php:8.4-zts-alpine Docker image, which compiles PHP from source with --enable-zts. Stock Alpine repos do not yet provide a ZTS PHP, so these packages are only safe to install on hosts running the same ZTS PHP build (the official Docker image is the canonical match).

curl -fsSL https://andreymashukov.github.io/php-parallax/alpine/keys/andreymashukov.rsa.pub \
    > /etc/apk/keys/andreymashukov.rsa.pub
echo "https://andreymashukov.github.io/php-parallax/alpine/zts/" \
    >> /etc/apk/repositories
apk update && apk add php-parallax
